# 使用手册

## 登录

管理员完成部署并创建账号后，使用分配的用户名和密码访问系统。社区版没有默认密码；忘记密码联系管理员，管理员可在服务器用用户管理 CLI 重置。退出登录按钮会撤销当前会话。

## 专线业务全量库

1. 选择来源类型，填写区域、客户名称、产品号码、业务状态、日期或综合关键字。
2. 点击“查询”。修改表单但没有再次点击查询时，列表和导出仍使用上次提交的条件。
3. 产品号码为精确匹配；客户名称、综合关键字支持包含匹配。重置会清空条件并重新查询。
4. 列表每页 20 条，可翻页；“详情”显示该记录完整原始字段。

来源“全部”显示公共列，其中业务带宽在传输接入方式之前。单一来源展示相应资源字段：互联网/IPVPN/多媒体显示 OLT、分光器及 IP；商务快线显示楼宇和 ONU 端口；传输专线显示 A/Z 端设备与电路。详情里的 `用户地址` 是源表 IP 字段，不是客户机房地址。

宽表可在表格内横向滚动；较长内容允许换行。KPI 和区域 Top 8 位于独立“统计分析”，不出现在查询页顶部。

## ONU 资源设备台账

填写 SN 码后点击“查询”，支持输入完整 SN 或片段；产品号码为精确匹配，客户名称和综合关键字支持包含匹配。可同时按区县、业务类型筛选。列表显示区县、客户名称、业务类型、产品号码、厂家、型号、SN 码、ONU 密码及 ONU 名称。

## 导出

exporter/admin 可点击“导出当前筛选”。导出不是只取当前页，而是从最近提交的筛选结果取最多 5000 条，格式为 UTF-8 CSV；超过上限请进一步筛选后分别导出。viewer 没有导出权限。日期、号码等字段在 Excel 中导入时可选“文本”，避免自动改变格式。

## 数据导入与批次

管理员将 Excel 文件放到服务器配置的 `IMPORT_DATA_DIR`，文件名和工作表与 `config/source_files.json` 对应。当前没有网页上传功能。

1. 打开“数据管理”，核对显示的导入目录。
2. 执行演练导入，随后刷新批次和异常记录，确认处理行数与错误。
3. 演练不更新业务表，但会写入批次/错误记录。
4. 确认后执行正式导入；按钮成功提示表示任务已启动，不代表已经完成。
5. 在“导入批次追踪”刷新，检查最终状态：SUCCESS 成功，PARTIAL_SUCCESS 有部分错误，FAILED 失败，DRY_RUN 为演练。

只串行发起导入。重复行按内容去重；修改后的行可能新增，源表删除行不会自动从库中删除。详情见 [DATA.md](DATA.md)。

## 用户、会话和日志

管理员在“用户管理”创建用户，选择 viewer（查询）、exporter（查询与导出）或 admin（管理）角色，密码至少 12 位。已有用户可调整显示名称、角色并点击保存，也可停用、启用、重置密码或删除。

不能删除当前登录管理员；系统对最后一个启用的管理员设有保护。CLI 属于维护工具，不应绕过管理页面去取消最后一个管理员。

会话管理可筛选用户、下线单个或整用户会话。当前管理员的整用户下线操作保留自己的当前会话；重置密码则撤销目标用户的全部旧会话。“数据管理”中的操作日志用于查看后台操作结果。

## 登录安全（管理员）

左侧“登录安全”提供三组操作，viewer/exporter 不可访问：

1. 查看限流与登录拒绝记录：按事件类型、来源 IP、账号精确筛选，支持最近 1/7/30 天和分页。等待时间是事件发生时的值，不是实时倒计时；旧日志可能没有账号或维度。
2. 调整规则：默认 900 秒内每账号 10 次、每 IP 60 次，成功与失败都计数。保存后不需重启，已有计数和到期时间保留，新阈值用于下一次登录。提示版本冲突时，先刷新再确认，不要盲目重试覆盖其他管理员的修改。
3. 临时封禁：填写单个 IPv4/IPv6、1–10080 分钟和原因，确认后禁止该 IP 新登录，到期自动恢复。重复设置会替换原因和到期时间。在生效列表点击“解封”，必须填写原因；该 IP 计数同时清除，账号自己的限流不受影响。

封禁不会踢掉已有会话；如需终止已登录访问，另到“用户管理”停用账号或强制下线。不支持网段或 MAC 封锁，不允许封禁回环或当前操作来源 IP。多人共用出口时，封禁可能影响整个出口，请先确认页面显示的实际来源与代理配置。

规则、封禁和解封均记录审计。历史操作在“数据管理 → 后台操作日志”查看，生效名单不展示已到期项。离线 `preview=1` 下该模块为只读演示。

## 常见情况

- 查询为空：先重置条件，检查产品号码是否完全一致，以及是否填写了不适用的日期。
- 未登录/登录失效：重新登录；账号可能被停用、改密或强制下线。
- 登录暂时受限：根据提示等待，或联系管理员核对“登录安全”的拒绝记录；刷新页面、重启 worker 不会清除数据库计数。
- 页面正常但数据失败：管理员检查 `/health`、数据库连接和应用日志。
- 导入目录不存在：检查服务器实际路径、运行用户权限及配置，不能填写自己电脑上的路径。
- 看见 DEMO 数据：检查 URL 是否含 `preview=1`。预览使用虚构数据，操作不会更新正式数据库，也不是正式业务验收。
