# 公网部署前验收清单

本清单不表示任意服务器已通过验收。必须在目标环境核对域名、证书、代理、防火墙、数据库、用户可见范围和恢复能力。不要把社区发布包或单元测试通过当作公网安全保证。

## 应用回归

```bash
python -m pytest -q
node --check web/app.js
node tests/frontend.cjs
node tests/frontend_security.cjs
bash -n deploy.sh
python scripts/check_release.py --tracked
python -m pip_audit
```

`tests/test_security.py` 使用虚构数据与内存 SQLite，覆盖六类修复及权限拒绝。前端脚本使用 Node VM，覆盖退出清理、旧响应拒绝、账号切换和跨标签页失效；这不是浏览器视觉验收。

真实 MySQL 集成检查使用明确指定的本地空测试库，库名必须以 `_test` 结尾，绝不能设置为业务库。示例不提供可复用的默认密码，按测试环境设置连接信息。

```bash
export MYSQL_TEST_DATABASE_URL='mysql+pymysql://TEST_USER:TEST_PASSWORD@127.0.0.1/dedicated_line_test'
python tests/mysql_smoke.py
python tests/mysql_security.py
python tests/mysql_login_security.py
```

第二个脚本必须紧跟第一个脚本在同一测试库运行；会在无账号/业务记录的测试库重构旧列形态并验证迁移，然后测试真实事务回滚、并发改密/全量下线、并发登录预算和遗留任务恢复。脚本包含 DDL，仅限一次性本地测试库。CI 配置覆盖 MySQL 8.0/8.4，实际是否通过以对应提交的运行记录为准。

## 导入模板校验

- 专线必需表头: 区域、客户名称、产品号码。
- ONU 必需表头: 客户名称、产品号码，以及 ONUID / SN码 / ONU名称 中至少一列。
- 保留额外原始列，空表头使用 `_col_N`；重复列名、缺失必需列、多个候选表头会报错，不继续猜测。
- 默认在配置的明细工作表前 20 行查找；不存在指定工作表时扫描工作表候选，必须只有一个有效表头。可在 `config/source_files.json` 对应文件配置中设置正整数 `header_row` 指定行，但仍必须通过字段校验。
- 未配置的文件名不自动映射为其他业务类型。所有文件先验证模板，再开始写业务记录。日志输出工作表、表头行、列数与数据行数，迁移时应逐表对账。
- 导入锁仅支持单机 API 多 worker 和 CLI，必须使用同一个绝对本地锁路径。禁止运行旧版导入器、删除锁文件或让另一台服务器同时导入同一库。

## 目标服务器门槛

- [ ] 可信 HTTPS、HTTP 跳转、证书续期和到期告警实际通过。
- [ ] 外网只开放必要 Web 端口；SSH 限制来源，应用 8000 和 MySQL 不直接公开。
- [ ] Nginx 限流有效，Uvicorn 仅信任实际代理地址，伪造 X-Forwarded-For 不能改变计数与日志来源。
- [ ] 两个 worker 共享数据库登录预算，超限返回 429，到期恢复；考虑为管理员增加 MFA/身份网关。
- [ ] 登录安全管理仅管理员可用；06 迁移、配置版本冲突、IP 规范化/自身保护、封禁到期、解封不清账号预算、审计失败回滚均通过。封禁仅约束新登录，不能替代会话撤销。
- [ ] 运行账号使用最小数据库权限；维护凭据不进入 Web 环境，代码只读，导入与日志目录单独可写。
- [ ] 退出、401、账号切换后清空敏感表格和详情，慢请求不能回填；浏览器后退和多标签页实测。
- [ ] 当前查询权限是全库权限，并包含 ONU 密码及完整 raw_data。只给有权查看全部这些数据的人员；需要区域/客户隔离时，先实现行级与敏感字段权限再开放。
- [ ] 认证、管理、导入日志保留与告警明确；没有密码/token 落日志。定期清理过期登录预算。
- [ ] CSP、HSTS 等浏览器安全策略按实际域名和资源实测启用，不盲目配置 preload 或所有子域。
- [ ] 用代表性数据量测试查询/导出的响应分位数、错误率、数据库慢查询和内存峰值。
- [ ] 备份加密、异机恢复、失败导入重试与升级回滚演练通过。

以上六项修复不会引入默认管理员，也不会自动改变原有完整原始数据可见需求。服务和真实数据迁移应另行授权并在维护窗口执行。
