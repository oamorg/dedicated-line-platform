# 数据格式与导入规则

默认文件名与工作表可在 `config/source_files.json` 修改。专线来源为互联网专线、IPVPN专线、多媒体语音专线、商务快线、传输专线；ONU 使用 `ONU台账.xlsx`。

常用列：

| 类型 | 原始列示例 |
| --- | --- |
| 专线公共 | 区域、客户名称、产品类型、产品号码、传输接入方式、业务带宽、开通日期、服开工单号 |
| 互联网/多媒体 | OLT端口名称、接入分光器、用户地址、网关地址 |
| IPVPN | 自带客户端互联IP、自带局端互联IP |
| 商务快线 | 楼宇名称、传输设备或ONU端口 |
| 传输专线 | A端传输设备名称、Z端传输设备名称、电路名称、业务相关地市 |
| ONU | ONUID、ONU名称、型号、ONU厂家、SN码、ONU密码、产品号码、客户名称、业务类型、客户端设备所属区县 |

`用户地址` 在页面显示为 IP 地址，不是客户机房地址。IPVPN 优先使用客户端/局端互联 IP；无值再兼容用户地址/网关地址。源字段完整保留在 `raw_data`。

解析器会尝试识别工作表及表头，实际映射以 `scripts/import_excel.py` 为准；导入前应演练检查实际选择的工作表和行数。源码不附真实 Excel 或生产数据库。

去重基于来源与行内容哈希。新增行写入、完全相同行去重；修改后的行可能新增，不是按产品号码覆盖；源文件删除行不导致库中删除。演练会写入批次和错误记录但不更新业务表。

前端 `?preview=1` 的企业、号码、SN、密码及地址均为虚构测试值，不能用于实际设备。预览只展示交互，不发出真实 API 请求，不证明数据库导入成功。
