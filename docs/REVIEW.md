# 社区发布审查记录

## 当前源码同步（2026-11-16）

本轮同步当前安全修订源码，不创建新 Release，不替换 v0.1.0 附件。以下历史章节记录旧版当时状态，其中“未内置限流”和“导入锁不跨进程”已由本次更新解决，不是当前能力说明。

- 管理操作和审计同事务；增加认证版本，修复改密/全量下线与并发登录的会话竞争。
- 数据库共享账号/IP 登录预算，管理员可配置规则、查看拒绝记录、临时封禁和解封 IP；规则版本和审计回滚有回归覆盖。
- 默认隐藏业务框架，退出、认证失败、账号切换和多标签页失效清除数据；过期响应不能回填。
- API/CLI 单机跨进程导入锁、遗留任务恢复与确定性 Excel 模板校验。
- 同步通用备份/恢复校验工具和合成数据测试，配置只保留标准安装路径；不自动安装定时器，不自动删除备份。
- 更新架构、部署、运维恢复和公网门槛；区分当前源码与旧 Release，反向代理只信任专用回环地址。
- 社区代码、测试和文档经独立本地回归与敏感内容检查后推送；对应提交的 Python/MySQL/依赖审计结果以 [Actions](https://github.com/oamorg/dedicated-line-platform/actions/workflows/ci.yml) 为准。

此次同步不连接生产数据库、不部署服务器、不上传业务数据、真实 Excel、私有配置、证书、迁移包或现场验收记录。源码回归不等同于新机、公网负载或浏览器完整验收。
